## O que você vai aprender

- SOLID

- KISS (Keep It Simple, Stupid)
- YAGNI (You Ain't Gonna Need It)
- Testes automatizados
- Versionamento com Git

## Princípios SOLID (resumo)

| Princípio | Significado |
|-----------|-------------|
| **S** - Single Responsibility | Uma classe deve ter um único motivo para mudar. |
| **O** - Open/Closed | Aberta para extensão, fechada para modificação. |
| **L** - Liskov Substitution | Subtipos devem ser substituíveis por seus tipos base. |
| **I** - Interface Segregation | Não force clientes a depender de interfaces que não usam. |
| **D** - Dependency Inversion | Dependa de abstrações, não de concretizações. |

> **Regra de ouro**: aplique esses princípios nos projetos de `05-projects/`.
