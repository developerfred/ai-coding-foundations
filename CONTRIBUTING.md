# Guia de Contribuição

Obrigado por querer contribuir com o **AI Coding Foundations**!

## Filosofia

Toda contribuição deve seguir: **fundamentos + crítica + clareza**.

Sempre inclua:
1. **Explicação** — o que é, por que importa.
2. **Código funcional** — que roda e pode ser testado.
3. **Testes** (quando fizer sentido).
4. **Notas de revisão** — o que foi revisado e por quê.

## Como contribuir

1. Escolha um módulo ou projeto em aberto (veja o status no README).
2. Crie uma branch a partir de `main`.
3. Escreva o conteúdo seguindo o formato dos arquivos existentes.
4. Revise criticamente: entenda cada linha, não copie código de IA sem entender.
5. Adicione testes quando aplicar.
6. Abra um Pull Request descrevendo o que mudou e por quê.

## Padrão de arquivos

Cada módulo deve ter um `README.md` com:
- Título e objetivo.
- O que o aluno aprende.
- Exemplo de código (com comentários).
- Checklist de revisão humana.
- Licença e créditos.
