# Pré-requisitos

Para aproveitar este repositório, você vai precisar de:

## Ferramentas essenciais

- **Node.js** (v18+) e **npm** — para rodar exemplos de JavaScript
- **Git** — para versionar seu progresso
- **Um editor de código** (VS Code, Cursor, etc.)
- **Terminal** com acesso a linha de comando

## Opcional (útil para módulos de IA)

- Conta em um provedor de LLM (Claude, OpenAI, etc.)
- Acesso a um agente de código (Claude Code, Cursor, GitHub Copilot)
- **Python** (v3.10+) — se quiser acompanhar exemplos de micrograd / Karpathy
- Todo o código do repositório está em JavaScript puro. Nenhuma dependência de TypeScript.

## Como começar

1. Clone ou baixe este repositório.
2. Leia `01-como-usar-este-repo.md`.
3. Comece por `01-fundamentals/01-algoritmos-e-complexidade/`.
4. Progrida na ordem dos módulos.
